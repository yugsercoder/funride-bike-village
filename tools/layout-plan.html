Site
Overview

Whole event site from KM 0 on Roxas Boulevard to the finish on Independence Road. The dashed red box is the Bike Village on page 1.

Booth type

  • Tent with back siding
  • Open tent
  • Merchant (open tent)
  • Booth stall only
  • Big booth
  • Aircon tent (VIP)
  • Stage

Key points

  1. Start: KM 0, Roxas Boulevard. Satellite Stage (12 × 12 ft, 3 ft high) on the KM 0 plaza.
  2. Standby per Wave feeds Exit to Start and the ramp up to KM 0.
  3. Entrance southeast corner, Exit southwest corner.
  4. Finish on Independence Road, beside BYD Garage and BYD Test Drive.
  5. Artists come in through the Artists Entrance and follow the path to the aircon tents.
